## Featured projects

### [AgriShield](https://github.com/NIKHILNIDAGUNDI/AgriShield)
Food security forecasting and risk-alert system using climate, pricing, and macroeconomic indicators to anticipate shortages and price pressure.

- Weather and CPI-driven forecasting
- Random Forest and neural-model comparison
- Risk threshold alert logic
- Data analysis and dashboard tooling

### [smart-fleet-routing-os](https://github.com/NIKHILNIDAGUNDI/smart-fleet-routing-os)
Transit operations and fleet scheduling platform for electric-bus planning, routing, charging, and dispatch visualization.

- GIS-based route planning
- Fleet telemetry and operational dashboards
- Multi-depot scheduling workflows
- Charger and substation planning logic

### [SFR-os-1](https://github.com/NIKHILNIDAGUNDI/SFR-os-1)
Public-facing fleet operations interface and deployment companion for the Smart Fleet Routing concept.

- Operations console presentation
- Dispatch and management UI
- Live web-hosted demo experience
