## Featured work

### AgriShield
A GPU-accelerated food security early warning system that uses weather and CPI data to forecast food price and shortage risk up to three months in advance.

- Predictive modeling for food security risk
- RAPIDS-powered GPU acceleration
- Policy alert logic for high-risk regions
- Repository: [AgriShield](https://github.com/NIKHILNIDAGUNDI/AgriShield)

### Smart Fleet Routing OS
An intelligent transit operations dashboard for electric bus fleet planning, charger management, route optimization, and depot operations.

- Interactive fleet operations console
- Fleet scheduling and dispatch workflow
- GIS-based route visualization
- Repository: [smart-fleet-routing-os](https://github.com/NIKHILNIDAGUNDI/smart-fleet-routing-os)

### SFR-os-1
A public-facing fleet operations interface designed to present dispatch and operational workflows in a modern, readable dashboard.

- Operations console for fleet activity
- Monitoring and workflow presentation
- GitHub Pages deployment
- Repository: [SFR-os-1](https://github.com/NIKHILNIDAGUNDI/SFR-os-1)
